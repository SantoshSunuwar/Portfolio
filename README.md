# 🌐 Santosh Sunuwar - Personal Portfolio Website

Welcome to my personal portfolio site! This is a simple, modern, and responsive website built to highlight my background, projects, work history, skills, and resume.

----------------------

## ✨ Features

* 📱 **Mobile Friendly:** Looks great on phones, tablets, and desktop computers.
* ⚡ **Interactive:** Smooth page navigation and interactive elements.
* 📄 **Easy CV Access:** View or download my resume in both PDF and image formats.

----------------------

## 🛠️ Built With

* **HTML5** – Code structure (`index.html`)
* **CSS3** – Page styling and colors (`style.css`)
* **JavaScript** – Animations and site functionality (`script.js`)

----------------------
